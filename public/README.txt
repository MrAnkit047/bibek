HOW TO USE
1. Put your photos in /images as 1.jpg ... 6.jpg (or edit the names in index.html).
2. Put your song in /music and name it song.mp3.
3. Edit the text inside the "EDIT YOUR CONTENT HERE" block in index.html.
4. Deploy: drag the whole bibek-birthday folder onto app.netlify.com/drop, or upload to Vercel / GitHub and import.
Tip: resize photos to ~1000px wide so it loads fast on mobile data.

VIDEOS
- Put short clips in /videos as 1.mp4, 2.mp4, 3.mp4 (H.264 .mp4 works on every phone).
- Keep each under ~15 MB (10-30 seconds is perfect) so they load fast. Free tools like HandBrake or CapCut can shrink them.
- Add or remove memories in the "memories" list inside index.html (type "photo" or "video").

NEW SECTIONS
- Our time together: set since:"YYYY-MM-DD" (the day you got together) in the content block. Left empty, the counter stays hidden.
- A message for you: record a voice note and save it as music/voice.mp3. If the file isn't there, the section stays hidden.
- Open when... and A secret for you: edit openWhen and secret in the content block.
- Play all: plays every photo (4 seconds each) and video in order.
